## Что это
PWA «Трекер дня»: чек-лист по блокам утро/день/вечер, отметки «в моменте», стоп-лист,
дневник, wish list с фото и датой, лекарства с частотой приёма. Без сборки и зависимостей:
`index.html` (разметка + CSS), `app.js` (вся логика), `sw.js` (офлайн-кэш), `manifest.webmanifest`, `assets/`.
Дизайн — система OWLS: фон `#F6F4EF`, чернила `#0B1E35`, акцент `#F26336`, Unbounded + Manrope.
Только светлая тема.

## Как устроен код (app.js)
- Состояние `S` в `localStorage` под ключом `owls.day-tracker.v1` (ключ не менять — данные пользователей).
  `seed()` — начальные данные, `migrate()` — доводит старые сохранения до текущей формы.
- `rollover()` — смена суток по локальной полуночи: сбрасывает галочки чек-листа, чипы, лекарства,
  поля дневника; растит счётчики стоп-листа; вчерашний день уходит в `history`.
- `streak()` — дни подряд; день засчитывается при ≥1 отметке чек-листа или чипа (лекарства не влияют).
- Экраны: `viewCheck/viewStop/viewDiary/viewWish/viewMeds`; порядок вкладок в `TABS`.
- Настройки — лист `#sheet` по нажатию на логотип: `sheetCheck/sheetStop/sheetMeds/sheetSet/sheetWish`.
  Всё добавление и удаление только там (плюс удаление записей дневника на главном).
  Черновики форм — в объекте `F`, не в `S`.
- Действия — объект `ACTIONS`, делегирование по `data-act`. Поля — `data-f` (черновики) и `data-draft` (дневник).
- Правила ввода: все текстовые поля ≤ 200 символов (`MAX_LEN`, плюс `maxlength` в разметке).
- Удаление — только удержание корзины 2 с (`DEL_MS`); клик показывает подсказку.
- Чип «в моменте»: касание +1, удержание 0,6 с — сброс (`HOLD_MS`).
- Радость: `splashAt()` — частицы (чек-лист, чипы, стоп-лист «Держусь», дневник, лекарства);
  `owlFor()` — совёнок для желаний. Вибрация `buzz()` — только Android; iPhone Safari не даёт.
- Лекарства: `every` (1/2/3/7) и `start` — приём в дни, где `(сегодня − start) % every == 0`.
- Переход между вкладками: `switchScreen(dir)` — новый экран въезжает со стороны нажатой вкладки
  (классы `go-l/go-r` на `#screen`, `go` на `.hd-t`). Подчёркивание в меню — один элемент `.nav-ul`,
  `moveNavUl()` двигает его под активную кнопку; `renderNav()` создаёт кнопки один раз, дальше только классы.
- Отклик на нажатие — CSS `:active` (scale), пружинка галочки — `.box.pop` + дорисовка штриха `tick`.
  Всё отключается через `prefers-reduced-motion`.
- Свайп между вкладками: обработчики pointer на `#screen`, направление фиксируется после 10 px
  (`SW_LOCK`), переход — при сдвиге больше четверти ширины или быстром флике от 44 px
  (`SW_PART`/`SW_FAST`/`SW_MIN`). Во время жеста экран едет за пальцем, `navUlAt()` двигает
  подчёркивание дробно. Флаг `swMoved` гасит клик, прилетевший сразу после свайпа.
- Каскад: `cascadeIn()` раздаёт `.rise` с шагом 30 мс (`RISE_STEP`, максимум `RISE_MAX` шагов).
  Запускается только при смене вкладки и на старте — `render(keepScroll, cascade)`, не при отметке.
- Кольцо прогресса — на всех вкладках через `ringCard(key, done, total, счёт, подсказка)`.
  `RING`/`NUMS` помнят прошлое значение вкладки, `afterRender()` доводит дугу и докручивает процент.
  Смысл кольца по вкладкам: чек-лист — пункты, лекарства — приёмы, стоп-лист — сколько держится,
  желания — исполнено, дневник — заполненные поля.
- Заставка `splash()` — случайная установка при запуске.
- Ошибка на старте → экран `#fatal` с кнопкой «Сбросить кэш и перезагрузить».
- Автообновление: при `controllerchange` страница перезагружается один раз; `reg.update()` при возврате.
- Excel (вкладка «Данные» в настройках): свой xlsx без библиотек — `zipStore` (zip без сжатия) + `xlsxBuild`
  на запись, `zipRead` (DecompressionStream deflate-raw, iOS 16.4+) + `xlsxParse` на чтение.
  Шаблон листов — `XL_SHEETS` (имя листа, заголовки), подсказки — `XL_HINT`. Импорт `xlImport()`:
  каждый лист заменяет свой список целиком, совпадение по тексту сохраняет id/отметки/фото;
  листов нет в файле — список не трогается; история объединяется. На iPhone файл уходит через `navigator.share`.

## При КАЖДОЙ правке — поднять версию в трёх местах
1. `index.html`: `<script src="app.js?v=N">`
2. `sw.js`: `const VERSION = 'owls-day-vN'` и `'./app.js?v=N'` в `ASSETS`
Иначе телефоны останутся на старой версии. Текущая версия — см. `grep -n "app.js?v" index.html`.
