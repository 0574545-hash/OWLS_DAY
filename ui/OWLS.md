# OWLS UI — стандарты дизайна

Система, по которой сделан «Трекер дня». Три файла, ни одной зависимости, без сборки.
Годится для любого небольшого приложения на телефоне: списки, отметки, формы, дневники.

## Подключить

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=Unbounded:wght@400;700;800&display=swap">
<link rel="stylesheet" href="owls.css">
<script src="owls-motion.js"></script>
```

По сети файлы лежат на `https://0574545-hash.github.io/OWLS_DAY/ui/owls.css` и `.../owls-motion.js`,
но для офлайн-приложения их лучше скопировать к себе.

Каркас страницы: `#app` → `.hd` (шапка) → `main#screen` (прокрутка) → `nav#nav` (меню).
Рабочий образец целиком — в `example.html`.

## Цвет

Один акцент на всё приложение. Оранжевый значит «действие» или «прогресс», больше ничего.
Зелёный и красный — только состояние, они не заменяют акцент и не красят кнопки.

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#F6F4EF` | фон приложения |
| `--card` | `#FFFFFF` | карточка |
| `--ink` | `#0B1E35` | заголовки, основной текст, тёмные плашки |
| `--ink-2` | `#2A3A52` | подписи полей, текст второстепенных кнопок |
| `--muted` | `#6B7280` | пояснения под заголовком |
| `--faint` | `#9AA1AB` | выполненное, время, плейсхолдеры |
| `--accent` | `#F26336` | кнопка действия, прогресс, выбранное |
| `--accent-soft` | `#FEEFEA` | фон выбранного элемента |
| `--line` | `#E1DCD0` | граница карточки и шапки |
| `--line-soft` | `#EFECE3` | разделитель строк внутри карточки |
| `--ok` / `--bad` | `#1E7A3C` / `#B43232` | «держусь» / «сорвался», ошибка |

Тёмной темы нет. Это осознанный выбор: приложение спокойное и бумажное, инверсия его ломает.

## Шрифты

**Unbounded** — заголовки, числа, надзаголовки. Всегда крупно или очень мелко, никогда в тексте абзаца.
**Manrope** — всё остальное.

| Роль | Класс | Размер |
|---|---|---|
| Надзаголовок | `.eyebrow` | 9.5, разрядка .18em, прописные |
| Заголовок экрана | `.h1` | 21–26, Unbounded 800 |
| Крупное число | `.big`, `.done-line` | 18 / 15, Unbounded |
| Заголовок секции | `.sec-t` | 13.5, Unbounded 700 |
| Основной текст | по умолчанию | 15 / 1.45 |
| Строка списка | `.item .txt` | 14 / 1.35 |
| Пояснение | `.hint`, `.note` | 12 |
| Мелкое | `.sec-s`, `.time` | 11.5 |

Поля ввода — строго 16 px, иначе iPhone увеличивает страницу при фокусе.

## Отступы

Шкала `--s1` 4 … `--s11` 28. Правила, которые держат ритм:

- Между карточками на экране — 14. Задаётся один раз через `gap` у `main`, не полями элементов.
- Поля экрана — 20 по краям, 18 сверху, 28 снизу, плюс безопасные зоны телефона.
- Внутри карточки — 16 по горизонтали, 16–18 по вертикали (`.pad`).
- Строка списка — 6 сверху и снизу, 16 по бокам, минимальная высота 52.
- Зазор между иконкой и текстом в строке — 12, между мелкими элементами — 8.

Группы выкладываются `flex` и `gap`, а не полями соседних элементов.

## Размеры

Главная кнопка 48, поле и второстепенная кнопка 44, поле в форме 46, строка списка 52,
кнопка меню 52. Ничего кликабельного меньше 44 быть не должно.

Радиусы: карточка 14, кнопка и поле 10, чип 8, чекбокс 7, пилюля и кружок — полный.

## Движение

Пять приёмов, больше не нужно. Всё отключается системной настройкой «Уменьшить движение».

**1. Переход между экранами.** Новый экран приходит со стороны нажатой вкладки, 260 мс.
Заголовок в шапке мягко поднимается. Подчёркивание в меню переезжает, а не перескакивает.

**2. Свайп.** Экран едет за пальцем. Переход при сдвиге больше четверти ширины или быстром
флике от 44 px. Меньше — экран возвращается на место.

**3. Каскад.** При смене экрана строки выходят по одной с шагом 30 мс, не дольше 14 шагов.
Только при смене экрана и на старте: на каждое касание список мигать не должен.

**4. Отклик на нажатие.** Кнопки и строки сжимаются до 0.96, отметка ставится пружинкой,
галочка дорисовывается. Вибрации на iPhone из браузера нет, это её замена.

**5. Прогресс.** Кольцо доезжает 550 мс, процент докручивается 500 мс, карточка пружинит
на новой отметке. Кольцо есть на каждом экране и всегда отвечает на один вопрос: сколько сделано.

Длительности берутся из токенов `--t-press` .12, `--t-base` .2, `--t-screen` .26, `--t-ring` .55.

## Модуль поведения

```js
OWLS.tabs({ screen, nav, keys, current: () => S.tab, go(key) { S.tab = key; render(); } });
OWLS.ringCard('today', done, total, '3 из 11 задач', 'Дальше: прогулка');
OWLS.afterRender(screen, S.tab);   // после каждой перерисовки: кольцо и процент
OWLS.cascade(screen);              // на старте
OWLS.hold({ onFire, onShort });    // удаление удержанием
OWLS.splash(el);                   // всплеск частиц
OWLS.toast('Сохранено');
OWLS.icon('tick', { size:13, color:'#fff', width:3 });
```

Иконки: сетка 24, обводка 1.6, скруглённые концы, без заливки. Набор в `OWLS.ICON`.

## Чего не делать

- Не добавлять второй акцентный цвет и не красить кнопки зелёным или красным.
- Не ставить поля ввода и кнопки добавления на главные экраны: всё создаётся в листе настроек.
- Не давать удалять одним касанием. Только удержание с видимой полосой.
- Не анимировать список на каждое действие, только на смену экрана.
- Не задавать отступы полями соседних элементов там, где работает `gap`.
- Не делать шрифт в полях меньше 16 px.
