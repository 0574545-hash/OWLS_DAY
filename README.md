# Трекер дня — OWLS

Веб-приложение для одного дня: чек-лист, стоп-лист, установки, список желаний и дневник.
Собрано на дизайн-системе OWLS. Открывается в браузере любого телефона и ставится на домашний экран.

## Что внутри

| Экран | Что делает |
| --- | --- |
| **Чек-лист** | Кольцо прогресса, серия дней, отметки «в моменте» со счётчиком (касание — +1, удержание — сброс), пункты по блокам утро / день / вечер — только те, что назначены на сегодня |
| **Стоп-лист** | Чего не делаю: счётчик чистых дней, отметка срыва обнуляет серию |
| **Лекарства** | Приём по блокам утро / день / вечер: название, форма (таблетка, капли, порция), количество, до / во время / после еды, частота (ежедневно, через день, раз в 3 дня, раз в неделю — отсчёт от дня добавления); галочки сбрасываются в полночь |
| **Wish list** | Желания с фото и датой, подсчёт «осталось / просрочено», отметка исполнения |
| **Дневник** | Настроение по пяти делениям, три поля, сохранение записи в историю |

**Настройки** открываются по нажатию на логотип. Удаление любого пункта — удержание корзины 2 секунды; поля ввода ограничены 200 символами. Там добавляются и удаляются пункты чек-листа (название, время, периодичность), отметки «в моменте», запреты, лекарства, установки и желания (название, дата, фото).

**Заставка.** При каждом запуске показывается случайная установка из вашего списка.

## Как это работает

- **Данные лежат только в браузере** (`localStorage`), никуда не отправляются и не требуют аккаунта.
- **Смена суток обрабатывается сама.** В полночь по времени телефона: галочки и отметки обнуляются, вчерашний день уходит в историю, у невыполненных запретов растёт счётчик чистых дней, поля дневника очищаются. Сохранённые записи, желания и установки остаются.
- **Серия дней считается по факту** — день засчитывается, если в нём была хотя бы одна отметка.
- **Периодичность.** Пункт можно назначить на каждый день, будни, выходные или выбранные дни недели. Блок (утро / день / вечер) определяется по времени: до 12:00 — утро, до 18:00 — день, дальше — вечер.
- **Правка позиций.** Нажатие на строку в настройках открывает её в форме сверху: строка подсвечивается, кнопка меняется на «Сохранить» рядом с «Отменить». Так же правятся записи дневника — черновик текущего дня при этом не теряется. У пункта чек-листа смена времени переносит его в другой блок.
- **Удаление** — только по удержанию корзины 1 секунду, с заливкой и полосой отсчёта. Короткое касание показывает подсказку.
- **Радость.** Отметка пункта, чипа, возврат к «Держусь» и сохранение записи — всплеск частиц; исполненное желание — совёнок с коротким словом. С вибрацией там, где браузер её даёт (Android; iPhone Safari — нет).
- **Фото желаний** уменьшаются до 420 px перед сохранением, чтобы не переполнять хранилище браузера.
- **Офлайн.** Service worker кэширует приложение при первом открытии.

## Запуск локально

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

> Открывать `index.html` двойным кликом (протокол `file://`) не стоит — не работают service worker и манифест. Нужен любой локальный сервер.

## Публикация на GitHub Pages

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/owls-day-tracker.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через пару минут приложение будет доступно по адресу `https://ВАШ_ЛОГИН.github.io/owls-day-tracker/`.

## Установка на телефон

- **iPhone (Safari):** Поделиться → «На экран "Домой"».
- **Android (Chrome):** ⋮ → «Установить приложение».

После установки приложение открывается на весь экран, без адресной строки, и работает без интернета.

## Файлы

```
index.html            разметка и стили
app.js                вся логика: состояние, экраны, смена суток
manifest.webmanifest  имя, иконки, полноэкранный режим
sw.js                 офлайн-кэш (меняйте VERSION при выкладке)
assets/               логотип и иконки приложения
```

Зависимостей и сборки нет. Шрифты Unbounded и Manrope подключаются из Google Fonts, при отсутствии сети подставляется системный шрифт.

## Что можно добавить дальше

- Экспорт дневника и истории в файл.
